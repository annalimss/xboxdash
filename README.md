🎮 Xbox Game Pass & Subscriptions Sales Dashboard
Bem-vindo(a) ao repositório do projeto! Este dashboard interativo foi desenvolvido no Excel para analisar e acompanhar o desempenho de vendas das assinaturas da linha Xbox, incluindo Xbox Game Pass, EA Play Season Pass e Minecraft Season Pass.

O objetivo principal foi transformar dados brutos de vendas em uma visualização limpa, intuitiva e funcional para tomada de decisões rápidas.

📌 Principais Recursos
Visualização Dinâmica de Indicadores (KPIs): Cartões de resumo com totais consolidados para cada tipo de assinatura.

Segmentação de Dados (Slicers): Filtro interativo por período de assinatura (Annual, Monthly, Quarterly) totalmente customizado para integrar-se ao design do dashboard.

Análise Visual Avançada: Gráfico interativo comparando o desempenho de vendas cruzando diferentes métricas.

Fórmulas Dinâmicas e Avançadas: Uso de GETPIVOTDATA (OBTERDADOSPARAVEL) para extração precisa de totais gerais (Grand Total) das Tabelas Dinâmicas, garantindo atualização automática dos cartões sem quebra de referências.

🛠️ Tecnologias e Ferramentas Utilizadas
Microsoft Excel: Construção de Tabelas Dinâmicas, modelagem de dados, fórmulas e design de UI/UX do Dashboard.

UI/UX Design no Excel: Personalização de elementos gráficos, remoção de contornos e harmonização visual baseada na identidade da marca Xbox.

📊 Estrutura do Arquivo
Dashboard: Painel principal estilizado com gráficos, slicers e cartões KPI.

Bases de Dados & Tabelas Dinâmicas: Abas de suporte onde a consolidação dos dados de vendas é processada antes de ser exibida no painel.

🚀 Como Visualizar o Projeto
Faça o download ou clone este repositório:

Bash
git clone https://github.com/annalimss/xboxdash.git
Abra o arquivo .xlsx no Microsoft Excel (de preferência na versão desktop para aproveitar toda a estilização personalizada da Segmentação de Dados).

Interaja com os botões do filtro Subscription Type para ver todo o painel e os gráficos se recalcularem em tempo real!
